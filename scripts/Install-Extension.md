# 加载 Chrome 扩展（一点即运行配套）

1. 打开**已有** Chrome（已登录 Options / config 里的 Gmail；不要为发信新开浏览器）。
2. 地址栏：chrome://extensions
3. 打开「开发者模式」
4. 「加载已解压的扩展程序」→ 选文件夹：  
   C:\tk邀约\tiktok-outreach\packages\send-plugin\extension
5. 改过 Options / JS 后点扩展卡片「重新加载」。
6. 先双击包根目录 一点即运行-发信插件.cmd 启动队列，再打开扩展选项：核对邮箱/模板/飞书表/节奏 → **保存参数** → **连接并启动**。
7. **不要**工作台、**不要**识别码、**不要**配对码。数据只记飞书。禁止超出节奏的群发。
