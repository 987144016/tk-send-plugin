TK Send Plugin · Gmail Web（多账号）

一点即运行。发信 = Gmail 网页点击。禁止 Gmail API / 远程调试 / 新开 Chrome。不要工作台、识别码、配对码。每邮箱只用自己的模板；禁止跨号。一人多号：每个 Gmail 标签页各自登录一个账号，扩展只领本页签登录号的任务，不再点头像切号；多个页签按顺序发。「立即发送（按Y人密送一封测发）」对每个剩余>0的账号入队1封密送，密送栏一次粘贴Y个邮箱（Y=「一次发多少人」；剩余=0跳过）。每个号发完先写飞书，再扫同号收件箱（含垃圾/可疑邮件）回写回复时间。节奏设置：「一次发多少人」= 这一批最多发几个人，发满就停，隔「批次间隔」分钟再发下一批；填 0 = 暂时禁用本号（不入队/立即发送跳过）。禁止一次性群发全部。
